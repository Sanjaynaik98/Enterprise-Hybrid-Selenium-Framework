\# Enterprise Hybrid Selenium Framework



\## Overview



Enterprise-level UI automation framework using

Java 21, Selenium 4, TestNG and Maven.



\## Technology Stack



\- Java 21

\- Selenium WebDriver

\- TestNG

\- Maven

\- Apache POI

\- Jackson

\- Log4j2

\- Extent Reports

\- Jenkins

\- GitHub



\## Application Under Test



https://demo.nopcommerce.com/



\## Framework Features



\- Hybrid Page Object Model

\- Data Driven Testing

\- Parallel Execution

\- Cross Browser Testing

\- ThreadLocal WebDriver

\- Logging

\- Extent Reporting

\- Screenshot Capture

\- Jenkins CI/CD



\## Execution



mvn clean test
